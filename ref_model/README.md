# ref_model

该目录用于存放标准、未改动的 VTM 24.0 参考执行模型的最小化基线副本。

## 当前目录约定

- `build/`：存放最小可运行的标准 VTM 24.0 基线可执行文件集合，默认仅保留运行所需的核心二进制。
- `cfg/`：存放编码与测试所需的配置文件。
- `script/`：存放运行脚本、批处理脚本以及后续性能测试脚本；当前包含 `roundtrip.sh`，用于完成编码、解码和重建一致性校验。

## 说明

当前环境下未检测到 `cmake`，因此尚未在本次操作中直接完成标准 VTM 24.0 的本地编译。
后续完成编译后，应仅将标准、未改动版本对应的 `build/` 目录复制到 `ref_model/`，无需复制整份源码。
